Portal de acolhimento de visitantes com quadros, listas, cartões, checklists, perfis, identidade visual e notificações.

== Installation ==
Envie o ZIP em Plugins > Adicionar plugin > Enviar plugin. Ative e abra Visitas > Abrir portal.
O plugin cria uma página Acolher. Shortcode: [visitas_portal]. Consulte o README.md para configuração e uso.
